🌊 Cla-Ro-Mar – Website Oficial

Sitio web institucional para Cla-Ro-Mar, complejo de departamentos de alquiler temporario ubicado en Mar del Plata.
El objetivo del proyecto es mostrar los departamentos, ubicación, servicios y facilitar el contacto con potenciales huéspedes.

🔗 Web en producción: https://claromar.com.ar/

🔗 Repositorio: https://github.com/FacuGorlero/Cla-Ro-Mar

🧱 Tecnologías utilizadas
Frontend

React.js

Vite (entorno de desarrollo)

JavaScript (ES6+)

JSX

Tailwind CSS (estilos y diseño responsive)

UI / UX

Componentes reutilizables

Diseño responsive (mobile first)

Íconos SVG embebidos

Accordion para contenido informativo

Galería de imágenes de departamentos

Estructura del proyecto

Arquitectura basada en componentes

Separación clara entre:

components/ui (botones, accordion, toast, etc.)

Componentes de dominio (Hero, Apartments, Location, Contact, WhyChooseUs)

Uso de hooks personalizados

Assets organizados en public/images
